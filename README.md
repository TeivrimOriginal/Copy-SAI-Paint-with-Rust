# TPaint — растровый редактор (аналог SayPaint)

Простой графический редактор для Windows, написанный на **Rust** с использованием
**Win32 API / GDI**: без сторонних UI-фреймворков, без C/C++-кода и без скомпилированных
зависимостей — весь проект собирается штатной командой `cargo build --release`.

Всё изображение рисуется в собственный 32-битный DIB-буфер и выводится на экран
через `BitBlt` — поэтому полотно **не мерцает** при рисовании.

![Скриншот](img/screenshot.png)

## Возможности

| Инструмент | Описание |
|---|---|
| Карандаш | Тонкая линия толщиной 1 px |
| Кисть | Линия выбранной толщины, со скруглёнными концами |
| Ластик | Рисует белым (цветом бумаги) |
| Линия | Прямая по нажатию и протягиванию |
| Прямоугольник | Контурный прямоугольник |
| Эллипс | Контурный эллипс |
| Заливка | Заливка замкнутой области (flood fill, 4 направления) |

Дополнительно:

- толщина линии: 1, 2, 3, 5, 8, 12, 16, 20 px;
- выбор цвета через стандартный диалог Windows «Цвет…»;
- **Отмена / Повтор** — история из 25 последних действий (Ctrl+Z / Ctrl+Y);
- **открытие и сохранение PNG** (Ctrl+O / Ctrl+S);
- очистка полотна;
- строка состояния: активный инструмент, цвет, размер полотна, координаты курсора;
- полотно изменяет размер вместе с окном, содержимое сохраняется.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` | Повторить |
| `Ctrl+O` | Открыть PNG |
| `Ctrl+S` | Сохранить PNG |

## Сборка из исходников

Нужен только [Rust](https://rustup.rs/) (stable). Весь код — чистый Rust,
Cargo сам подтянет зависимости с crates.io.

```bat
cargo build --release
```

Готовый файл: `target\release\tpaint.exe` (~480 КБ). Он собран со статической
линковкой CRT и тянет за собой только системные библиотеки Windows
(`kernel32`, `user32`, `gdi32`, `comdlg32`) — запускается на «голой» Windows 10/11.

На Windows для линковки нужен C-линковщик от Visual Studio — это штатное требование
toolchain `x86_64-pc-windows-msvc`:

- установите [Visual Studio Build Tools 2022](https://visualstudio.microsoft.com/downloads/)
  с компонентами «MSVC v143» и «Windows 10/11 SDK»;
- либо, если Visual Studio нет, добавьте таргет MinGW-w64:

```bat
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

(в этом случае нужен установленный MinGW-w64, например winlibs, с `gcc` в `PATH`.)

### Зеркало crates.io

В репозитории есть файл `.cargo/config.toml` с заменой crates.io на зеркало USTC —
это нужно в сетях, где `crates.io` недоступен. Если прямой доступ к crates.io
работает, просто удалите этот файл.

## Структура проекта

```text
src/
  main.rs    — окно, панель инструментов, диалоги, обработка сообщений Win32
  app.rs     — состояние приложения, инструменты, история undo/redo
  canvas.rs  — буфер полотна, фигуры, заливка, чтение/запись PNG
```

Весь код — Rust; C в проекте нет.

## Зависимости

Обе зависимости — чистый Rust:

- [`windows-sys`](https://crates.io/crates/windows-sys) 0.60 — привязки Win32
  (генерируются из метаданных Windows, собственного C-кода не содержат);
- [`image`](https://crates.io/crates/image) 0.25 с фичей `png` — кодирование
  и декодирование PNG.
